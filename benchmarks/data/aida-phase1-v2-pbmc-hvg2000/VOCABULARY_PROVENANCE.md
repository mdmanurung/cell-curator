# Provenance of the PBMC marker vocabulary

PROVENANCE AND SCOPE. This vocabulary is a pre-declaration, written before any AIDA cluster was inspected, and it is transcribed from standard human PBMC immunology rather than from these data. It is NOT derived from, fitted to, or checked against the AIDA labels, the AIDA clusters, or any Azimuth/CellTypist/scANVI output. The declared limitation is real and is recorded in benchmarks/README.md: this package is being evaluated with priors that the agent performing the evaluation also wrote, which inflates the result relative to a vocabulary obtained independently. The neutral substitution is a published PBMC marker panel such as PanglaoDB or a public Azimuth l2 marker set, and the circularity table would have to be re-checked if that substitution were made. Granularity is deliberately the conventional ~14-way PBMC split, coarser than the AIDA fine subtypes, so the benchmark measures whether a cell was found rather than whether it was named at the annotator's chosen depth. The three granularity tiers in benchmark.py exist to make that difference measurable instead of hiding it.
